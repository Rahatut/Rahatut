# About Me

CSE undergraduate at Islamic University of Technology currently doing research in NLP & AI : Resource constrained efficiency improvement of reasoning of language models, mainly SLMs. 

My area of interests : 
- Building projects integrating AI
- Simulations of systems (Natural and Theoretical) & visualizations
- Machine Learning & Data Analysis
- Networking, Cloud and Home server
- Linux
- Web apps (Backend and Frontend engineering)
- Designing interfaces, prototyping, and UI/UX design
- System design, DevOps

I like building things that let me have full customization and configuration control and prefer using tools and resources as efficiently as possible. Moreover I like interpreting things as systems each module of which follow "Cause and Effect" rule. The effects/outputs are inputs to be traced to the module responsible and tweaked if needed. Theoretical concepts reinforce and improve the traceability. As a visual learner, visualizing these systems with design and diagrams is how I work.
